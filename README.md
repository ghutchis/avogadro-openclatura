# avogadro-openclatura

An Avogadro 2 plugin that names the current molecule using
[OpenClatura](https://pypi.org/project/openclatura/).

It adds a single menu item under **Analyze → Properties → Clatura Name…**
which converts the molecule to a canonical SMILES (via RDKit) and reports
the generated IUPAC-style name in a dialog.
